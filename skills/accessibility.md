# Accessibility

- Every interactive control must work with the keyboard alone.
- Use native elements before ARIA; ARIA only when native is impossible.
- Every input needs a visible label or an accessible name.
- Keep a visible focus indicator.
- Do not encode meaning with colour alone.
- Text contrast should meet WCAG AA.
- Test the tab order and the main action with a screen reader when possible.
