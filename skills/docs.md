# Documentation

- A README answers: what it is, requirements, install, first run, commands, tests.
- Put the shortest working example first.
- Docstrings say what a function does, its arguments and its return value.
- Document the why and the constraints, not the obvious syntax.
- Every command in the docs must be copy-pasteable and current.
- Update the docs in the same change as the code they describe.
- Write documentation in English.
