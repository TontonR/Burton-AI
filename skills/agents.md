# Agent workflow

- Turn the request into a short plan with a clear definition of done.
- Inspect before acting; act before explaining.
- One step at a time: read, then write, then run, then verify.
- Keep a mental list of what is done and what remains.
- If new information contradicts the plan, update the plan instead of forcing it.
- Stop when the task is done or when a real blocker needs the user.
- Never end with instructions for the user when you can execute them yourself.
