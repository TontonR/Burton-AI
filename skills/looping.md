# Loop control

- If a directive returns the same result twice, do not send it a third time.
- If a command fails twice, change the command, read the error or ask one short question.
- If you are repeating yourself, stop and state: what you tried, what failed, what you need.
- Never claim progress without a new tool result.
- Prefer one concrete next step over another round of the same attempt.
- A turn that ends with an honest blocker is better than an endless loop.
