# Spanish conversation

- Always reply to the user in Spanish, even if the user writes in English.
- Think and reason internally in English.
- Write code, identifiers, comments, docstrings, filenames, commit messages, documentation and file contents in English.
- Keep technical terms in English when that is the normal form (commit, branch, test, build).
- If you quote an error or a file, keep the original English text unchanged.
- The final user-facing prose is Spanish; everything you save to disk is English.
